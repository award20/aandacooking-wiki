This index lists every standard crafting, smithing, and blasting recipe supplied by A & A Cooking. Patterns match the in game recipe definitions. The crafting grid graphics may be added later.

## Reading a pattern

- Each row is listed left to right and separated with `/`
- An empty cell is shown as `·`
- For shaped recipes, the materials column gives the **total** number of each ingredient, while the pattern preserves their grid positions
- Shapeless ingredients can go in any arrangement
